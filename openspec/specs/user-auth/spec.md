# user-auth Specification

## Purpose
让教师和学生通过用户名 + 密码进行认证、建立已认证会话、把受保护页面与端点置于登录闸门之后，并提供下游授权决策所依赖的教师/学生角色身份。

## Requirements

### Requirement: 账号使用用户名和密码登录

系统须（SHALL）允许教师和学生通过提交用户名和密码进行认证。凭据正确时系统须（SHALL）返回成功响应（2xx）并建立已认证会话；凭据错误时系统须（SHALL）拒绝登录且不建立会话，并不透露是哪个字段错误。

#### Scenario: 教师登录成功

- **WHEN** 教师提交正确的用户名和密码
- **THEN** 系统返回 2xx 并设置已认证会话，使后续带该会话的请求被视作已登录（判定通过：响应 2xx + 会话 Cookie 被设置 + 下一受保护请求不再重定向到 /login）

#### Scenario: 学生登录成功

- **WHEN** 学生提交正确的用户名和密码
- **THEN** 系统返回 2xx 并设置已认证会话（判定通过：同上）

#### Scenario: 凭据错误不建立会话

- **WHEN** 调用方提交不存在的用户名或错误密码
- **THEN** 系统返回失败状态且不设置会话，并以通用"凭据无效"错误拒绝、不指明哪个字段错（判定通过：响应非 2xx + 无会话 Cookie + 响应体不区分用户名/密码错误）

### Requirement: 未登录访问受保护资源被引导到登录页

系统须（SHALL）对每个受保护页面与端点要求已认证会话。未认证的浏览器页面导航须（SHALL）被重定向到登录页；未认证的 API 调用须（SHALL）返回需要认证状态，且不返回受保护内容。

#### Scenario: 未登录访问页面被重定向到登录页

- **WHEN** 未登录用户导航到受保护页面
- **THEN** 系统返回 302 重定向到 /login 且不返回受保护内容（判定通过：响应状态码 302 + Location 指向 /login）

#### Scenario: 未登录调用 API 被拒

- **WHEN** 未登录调用方调用受保护 API 端点
- **THEN** 系统返回 401 且响应体不含任何受保护数据（判定通过：响应 401 + 响应体无受保护数据）

#### Scenario: 已登录请求通过闸门

- **WHEN** 已登录用户请求受保护资源
- **THEN** 系统返回 200 且提供该受保护资源（判定通过：响应 200 且非重定向）

### Requirement: 教师与学生角色

系统须（SHALL）为每个账号指定唯一角色：教师或学生。已认证会话须（SHALL）携带调用方角色，使授权决策无需重新读取凭据。

#### Scenario: 会话携带角色

- **WHEN** 用户登录成功
- **THEN** 产生的会话标识该用户角色为教师或学生（判定通过：会话中可读出 role 且取值为 teacher 或 student 之一）

### Requirement: 登出清除已认证会话

系统须（SHALL）提供登出操作以清除调用方的已认证会话。登出后该会话须（SHALL）不再可用于访问任何受保护资源。

#### Scenario: 登出后受保护资源不可访问

- **WHEN** 已登录用户登出后再请求受保护资源
- **THEN** 系统返回 302 重定向到 /login 或 401，且不再以原会话提供服务（判定通过：登出后用原会话 Cookie 访问受保护资源得到 302→/login 或 401）

### Requirement: 密码必须哈希存储，禁止明文

系统必须（MUST）仅以加盐哈希形式存储账号密码。明文密码不得（MUST NOT）持久化于数据库、日志、备份或错误信息中。密码校验须（SHALL）对提交的密码做哈希并与已存哈希比较，绝不读取或比较明文。

#### Scenario: 密码以哈希存储

- **WHEN** 创建账号或设置密码时
- **THEN** 系统仅持久化该密码的加盐哈希，绝不存储明文（判定通过：用户表 password_hash 字段为哈希且 ≠ 明文密码）

#### Scenario: 通过哈希比较校验密码

- **WHEN** 登录时比对提交的密码
- **THEN** 系统对提交内容做哈希并与已存哈希比较，不读取或比较明文（判定通过：正确密码通过、错误密码失败，且过程不涉及明文比对）

#### Scenario: 明文绝不记录入日志

- **WHEN** 登录或建账号过程中发生错误
- **THEN** 系统不在日志或错误响应中包含明文密码（判定通过：日志与错误响应中检索不到明文密码）

### Requirement: 密钥只存放在服务端环境变量中

系统须（SHALL）仅从服务端环境变量在运行时读取签名密钥与其他密钥。密钥不得（MUST NOT）嵌入源码、提交进仓库的配置文件，或容器镜像层中。当必需密钥缺失时，系统必须（MUST）拒绝启动。

#### Scenario: 密钥来自环境变量且缺失即拒启

- **WHEN** 服务启动
- **THEN** 它从环境变量读取签名密钥与密钥；若必需密钥缺失则拒绝启动（判定通过：不设 SECRET_KEY 时进程退出并报错）

#### Scenario: 密钥不存在于代码或镜像

- **WHEN** 检查源码仓库或构建好的容器镜像
- **THEN** 源码、已提交配置或镜像层中均不存在任何密钥值（判定通过：在仓库与镜像中搜索不到密钥值）
