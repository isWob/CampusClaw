# Add Traceable Vector Retrieval

## Why

第 3 课交付了登录认证、角色权限与班级隔离的材料上传入库，但教师和学生只能浏览材料清单：想找「某个知识点在哪份材料的哪一段」，只能逐份下载翻阅。第 4 课要求在同一系统上实现可追溯的知识库检索：本班范围内完成正文切分、向量嵌入与入库，支持关键字、向量与混合三种检索，每条命中都能回溯到原文出处；当本班材料中不存在依据时，明确返回「资料中未找到相关内容」，不得编造出处。

## What Changes

- 上传的材料在入库后自动完成知识库索引：提取正文（body_text）→ 切分为切片 → 逐片向量嵌入 → 写入向量库；存量种子材料在启动时以默认策略幂等补齐索引。
- 支持三种切分策略：`auto`（默认，最大 800 字窗口、重叠 80 字、优先在空行/换行/句号断开）、`custom`（自定义分隔符、长度 100–2000 字、重叠 0%–50%、可选预处理）、`hierarchy`（按 Markdown 标题分章）；教师可对已入库材料按新策略重建索引（先删旧切片与旧向量再重新写入）。
- 新增班级范围检索接口：`keyword`（仅查关系库全文索引，不调用嵌入、不访问向量库）、`vector`（问句经服务端嵌入 → 向量库按会话班级过滤 → 余弦相似度低于 0.35 的候选丢弃 → 回关系库取正文）、`hybrid`（两路各自过滤后按名次 RRF k=60 融合，缺席一路不贡献分数；为默认模式）。
- 每条命中可溯源：材料标识与标题、切片序号、字符区间、摘录（取自关系库切片正文）与打开对应材料的入口；响应不含磁盘路径与向量分量。
- 失败语义：空查询 400；无命中 200 + 空 hits +「资料中未找到相关内容」，不得以低相关候选凑数；向量库或嵌入不可用时 keyword 仍可用，vector/hybrid 返回 503 且不编造分数。
- 新增问答端点（先检索后生成）：混合检索取本班前 4 条切片，有命中才调用对话网关生成简短回答，回答中 [n] 标注与 citations 顺序一致；无命中直接返回固定文案、不调用生成模型；客户端注入的 system 消息被丢弃；不做流式输出。
- **安全**：班级标识仅取自登录会话，请求中携带的 class_id 一律丢弃；跨班检索对外表现为无命中（不以 403/404 泄露存在性）；向量库与嵌入/对话网关不对客户端暴露，密钥仅存服务端环境变量；页面不展示向量分量。
- **运维**：Compose 增加向量库服务（仅内部网络，不映射宿主端口）；嵌入与对话经环境变量配置的 OpenAI 兼容网关（默认课程网关）。

## Capabilities

### New Capabilities
<!-- 引入的能力。路径段使用 kebab-case，每个对应 specs/<capability-path>/spec.md。 -->
- `knowledge-retrieval`：正文切片与索引建立（三种切分策略、嵌入、向量库写入、教师重建索引、种子补齐）、班级范围的三模式检索（关键字/向量/混合 RRF）、内容溯源、空查询与降级语义、先检索后生成的问答与引用标注。

### Modified Capabilities
<!-- 在现有能力上扩展。 -->
- `class-materials`：教师上传成功后，正文（body_text）须从文件内容中提取并保存，作为知识库切分与索引的输入；正文与原文件保持上传原样，不做改写。

## Impact

- **新增代码**：切分器（三策略）、嵌入客户端、向量库访问层、检索编排（RRF）、问答编排；新增端点：检索、问答、按材料重建索引。
- **新增依赖**：`qdrant-client`（向量库客户端）、`httpx`（网关调用）；Compose 新增 `qdrant` 服务（容器内网络，不暴露宿主端口）。
- **数据模型**：`materials` 增加 `body_text` 列；新增 `knowledge_chunks` 表（切片正文、序号、字符区间、嵌入状态）与配套全文索引（SQLite FTS5，中文按 2-gram 预切分，对齐课件 ngram token=2 口径）；Qdrant 集合 `campusclaw_chunks`（余弦度量，payload 仅存标识）。
- **配置**：新增 `QDRANT_URL`、`EMBEDDING_BASE_URL/EMBEDDING_API_KEY/EMBEDDING_MODEL`、`CHAT_BASE_URL/CHAT_API_KEY/CHAT_MODEL` 等环境变量（均可选；缺失时以降级模式启动），密钥绝不入库。
- **兼容性**：不修改既有登录/上传/列表/详情/下载行为与响应契约；旧数据由 bootstrap 幂等补齐正文与索引，无手工迁移。

## Non-Goals

本课程本次变更**不做**以下内容（不在范围内）：

- 流式输出与多轮会话管理（第 5 课）。
- 交叉编码器重排序、语义切分与「子切片检索/父块生成」等高级 RAG 技术。
- 编排框架（LangChain/LlamaIndex/Dify 等）；切分、嵌入与检索由本服务自行实现，便于对照规约逐条验收。
- 材料在线编辑、预览渲染、版本管理与去重；上传类型仍仅限 `.txt`/`.md`（沿用第 3 课白名单）。
- 多副本、高可用与向量库分片；单实例部署边界不变。
