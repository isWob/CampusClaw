# tutor-agent Delta

## ADDED Requirements

### Requirement: 教师可保存助手系统提示词且下一轮对话生效

系统须（SHALL）允许教师保存一份系统提示词，规定助手的角色与行为边界。提示词须（SHALL）按教师所在班级生效，同班学生提问时助手须（SHALL）受该提示词约束。教师保存提示词后，须（SHALL）从下一轮对话开始生效（当前轮仍用旧提示词）。学生不得（MUST NOT）查看或修改提示词。未登录调用必须（MUST）返回 401；学生调用必须（MUST）返回 403。

#### Scenario: 教师保存提示词后下一轮生效

- **WHEN** 教师保存新提示词，随后学生在新一轮对话中提问
- **THEN** 助手该轮回答受新提示词约束，保存前的进行中轮次仍受旧提示词约束（判定通过：保存后新一轮对话网关输入的 system 含新提示词内容）

#### Scenario: 学生不可查看或修改提示词

- **WHEN** 学生调用提示词读取或写入端点
- **THEN** 系统返回 403 且不返回提示词正文（判定通过：响应 403 + 响应体无提示词内容）

#### Scenario: 未登录调用提示词端点被拒

- **WHEN** 未携带有效会话调用提示词端点
- **THEN** 系统返回 401 且响应不含提示词正文（判定通过：响应 401 + 无提示词内容）

### Requirement: 教师可开关解题引导技能且回答方式须明显不同

系统须（SHALL）允许教师开启或关闭解题引导技能。技能开启时，助手须（SHALL）只给解题思路并引用本班材料的标题与位置，不得（MUST NOT）直接给出最终答案；技能关闭时，助手对同一问题的回答方式须（SHALL）明显不同（可直接给出答案）。技能状态须（SHALL）按教师所在班级生效，且须（SHALL）与提示词在同一轮回答中同时生效。学生不得（MUST NOT）开关技能。未登录调用必须（MUST）返回 401；学生调用必须（MUST）返回 403。

#### Scenario: 技能开启只给思路不直接给答案

- **WHEN** 教师开启解题引导技能后学生就某题目提问且本班知识库有相关切片
- **THEN** 助手回答以解题思路为主并引用材料出处，回答中不直接给出最终答案（判定通过：回答含思路与 [n] 出处标注 + 无最终答案直接陈述）

#### Scenario: 技能关闭后回答方式明显不同

- **WHEN** 教师关闭解题引导技能后学生就同一题目提问
- **THEN** 助手回答方式与技能开启时明显不同，可直接给出答案（判定通过：关闭后回答含直接答案 + 与开启时回答风格可区分）

#### Scenario: 学生不可开关技能

- **WHEN** 学生调用技能开关端点
- **THEN** 系统返回 403 且技能状态不变（判定通过：响应 403 + 技能状态字段未变更）

### Requirement: 助手回答须同时用上提示词技能与本班检索结果

系统须（SHALL）在每次提问时同时使用已保存的提示词、已启用或关闭的技能状态与本班知识库的混合检索结果来生成回答。系统须（SHALL）先以会话班级执行混合检索取前 4 条切片；命中时须（SHALL）在回答中标注出处，无命中时须（SHALL）说明「资料中未找到相关内容」且不得（MUST NOT）编造出处。班级标识须（SHALL）仅取自登录会话。客户端注入的 system 消息必须（MUST）被丢弃，系统提示词须（SHALL）由服务端从已保存提示词与技能状态组装。

#### Scenario: 三者同轮同时生效

- **WHEN** 教师已保存提示词并开启技能，学生提问且本班知识库命中
- **THEN** 对话网关输入的 system 消息同时含教师提示词、技能约束段与检索材料段（判定通过：网关输入 system 含三段内容 + 回答受三者共同约束）

#### Scenario: 无命中不编造出处

- **WHEN** 学生提问且本班知识库无相关切片
- **THEN** 助手返回「资料中未找到相关内容」且 citations 为空，不调用对话网关（判定通过：固定文案 + 空 citations + 网关无调用记录）

#### Scenario: 客户端 system 消息被丢弃

- **WHEN** 请求体中携带客户端构造的 system 消息调用助手端点
- **THEN** 该消息不进入对话网关输入，服务端仍以自己的提示词、技能状态与检索结果组装 system（判定通过：网关输入不含客户端 system 内容）

#### Scenario: 班级仅取自会话

- **WHEN** 请求体中携带他班 class_id 调用助手端点
- **THEN** 系统仍以会话班级为检索范围，响应中不出现他班切片（判定通过：携带与不携带 class_id 两次响应一致 + 无他班内容）

### Requirement: 助手回答以 SSE 流式逐段返回

系统须（SHALL）以 Server-Sent Events（SSE）逐段返回助手回答。每个 SSE 事件须（SHALL）以 `data:` 前缀与两个换行符结尾。命中切片的 citations 须（SHALL）在流式回答开始前以独立事件下发。对话网关不可用时，有命中须（SHALL）返回固定说明文案且不调用网关，无命中仍须（SHALL）走固定文案路径。端点不得（MUST NOT）返回向量分量或他班切片。

#### Scenario: SSE 流式逐段返回

- **WHEN** 学生提问且本班知识库命中且对话网关可用
- **THEN** 响应 Content-Type 为 text/event-stream，回答分多个 SSE 事件逐段到达（判定通过：Content-Type=text/event-stream + 响应体含多个 data: 事件）

#### Scenario: citations 在流式回答前下发

- **WHEN** 助手端点开始流式响应
- **THEN** citations 事件先于回答正文事件到达客户端（判定通过：首个非结束事件为 citations + citations 含命中切片溯源字段）

#### Scenario: 对话网关不可用时返回固定说明

- **WHEN** 对话网关未配置且本班知识库有命中
- **THEN** 助手以 SSE 返回「检索到相关内容，但对话服务未配置」说明且不调用网关（判定通过：SSE 响应含固定说明 + 网关无调用记录）

### Requirement: 对话历史按会话保存且支持连续追问

系统须（SHALL）把对话历史按会话保存，会话须（SHALL）归属当前用户与班级。后续轮次须（SHALL）把此前若干轮对话作为上下文输入对话网关。会话标识由系统生成；请求不携带会话标识时须（SHALL）新建会话。跨用户或跨班级的会话须（SHALL）对外表现为不存在。

#### Scenario: 连续追问带历史上下文

- **WHEN** 学生在同一会话中连续提问多轮
- **THEN** 后续轮次的对话网关输入含此前若干轮 user/assistant 消息（判定通过：第二轮网关输入含第一轮的 user 与 assistant 内容）

#### Scenario: 不携带会话标识新建会话

- **WHEN** 调用助手端点且请求不携带 session_id
- **THEN** 系统新建会话并返回会话标识（判定通过：响应含新 session_id + 库中存在该会话行）

#### Scenario: 跨用户会话表现为不存在

- **WHEN** 调用方携带不属于自己或不存在的 session_id
- **THEN** 系统视为会话不存在并新建会话，不泄露他班会话内容（判定通过：携带他班 session_id 得新会话 + 不返回他班历史消息）
